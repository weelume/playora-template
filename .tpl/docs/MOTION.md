## 本轮实际验证

独立生产实例的 PC/iPad/H5 均实际触发故事窗口开始、放大与文案完全显现；窗口1→约28.4倍，文案透明度0→1。三端实际触发翻卡与返回、FAQ展开、视频暂停与恢复。H5菜单切页关闭、语言保留查询和锚点、表单本地校验通过。

故事文案曾因直接 opacity 动画通道未按滚动更新而隐藏；仅关闭动画继承未解决，最终以独立 CSS 变量驱动透明度，并在三端运行态确认修复。原站细分时序、全部悬浮轨迹与系统减少动态偏好仍未完成完整对照，原站浏览器多次超时；本轮不宣称完整动效复刻验收通过。

1.0.1 将根滚动容器定位限定为 html:has(.po)，避免开发环境对静态根容器的测量警告；主题只在当前模板挂载时生效。bundle 依当前包版本选择归档，防止多次打包误选旧版本。
